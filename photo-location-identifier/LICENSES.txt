The place packs are collective databases. Their OpenStreetMap layer is (c) OpenStreetMap contributors, available

4. Not included
---------------

pillow-heif is not used. Its own code is BSD-3-Clause, but its Windows wheels bundle libheif and libde265 (LGPL-3.0)
and the x265 encoder (GPL-2.0), and HEVC (the picture coding inside HEIC files) is covered by patent pools. This
program only needs the details saved with a HEIC picture (its EXIF), so it reads them from the file's boxes itself,
with no HEIC decoder: HEIC and HEIF photos are fully supported without pillow-heif.

piexif is not used (Pillow writes and reads EXIF on its own).

ffprobe (FFmpeg) is not included. If you install it yourself, the program uses it to read the location of videos.
